# AMR brand assets

**AMR** is the company. Its mark is the lowercase rounded `amr` monogram below.
The shape is fixed: use these files, never redraw, stretch or re-letter it.
Products have their own names (SELF, Vision, Cut…) and do not repeat "AMR" next to the mark.

## Monogram colourways

| File | Use |
| --- | --- |
| `amr-silver-copper.png` | Main mark. Dark backgrounds; app header in Graphite and Light themes |
| `amr-green-gold.png` | Saudi theme, Saudi-market materials |
| `amr-green-silver.png` | Alternative for green or light backgrounds |
| `amr-black.png` | One-colour mark on light backgrounds, print, documents |
| `amr-white.png` | Outline mark; light backgrounds where a lighter feel is wanted |

All files are transparent PNG, 1600 px wide.

## In the app (`public/`)
- `amr-mono.png` — header mark (silver-copper), 56 px tall for sharp 2× display.
- `amr-mono-saudi.png` — header mark in the Saudi theme (green-gold).
- `icon-*.png`, `apple-touch-icon.png`, `favicon.png` — the **SELF** app icon (product icon, not the company mark).
- `self-icon-1024.png` in this folder — SELF icon master.

Palette: cyan `#00D4FF`, teal `#007C8A`, copper `#C77B3A`, silver `#D6D9DD`, black `#0B0F14`; Saudi theme: green `#03130C`–`#0E3323`, matte gold `#D3B05A`.

## App colourway (from 2026-11)

`amr-bronze.png` — one flat brushed-bronze colour (soft top-to-bottom tone, no gloss or highlights),
used in SELF on every theme, light and dark. Shape is the original monogram's alpha mask, unchanged.

`amr-3d-bronze.png` (in the app) and `amr-3d-blue.png` (spare) — same monogram with a soft bevel,
a light outline ring and a small shadow, so it reads on light and dark backgrounds. Shape unchanged.
