# AMR brand assets

Approved AMR monogram. Use these files; do not redraw or recolor the mark.

| File | Use |
| --- | --- |
| `amr-monogram.svg` | Vector master: site, print, any size |
| `amr-monogram-1024.png` | Transparent PNG for places that need a bitmap |

App copies generated from the 4096 px master live in `public/`:
`amr-mono.png` (header), `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`
(mark inside the safe zone), `apple-touch-icon.png`, `favicon.png`.
Background behind the mark in icons: `#0B0E11`.

Palette: cyan `#00D4FF`, teal `#007C8A`, copper `#C77B3A`, silver `#D6D9DD`, black `#0B0F14`.
